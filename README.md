# 현장 지시 카드

외국인 근로자가 섞인 제조 현장에서, 반장의 작업 지시를 **쉬운 한국어로 바꾸고 → 근로자별 모국어 카드로 보내고 → 누가 이해했는지 확인**하는 웹앱입니다.

천안의 한 제조업체에서 베트남·네팔·우즈베키스탄 근로자 8명이 섞인 조를 맡은 현장 반장을 위해 만들었습니다.

## 왜 만들었나

- 반장은 "시마이", "단도리" 같은 현장 용어를 쓰는데, 일반 번역 앱은 이 말을 잘못 옮깁니다. 결국 손짓으로 다시 설명하게 됩니다.
- 안전 수칙을 전달해도 누가 이해했고 누가 못 했는지 알 방법이 없습니다.

## 주요 기능

1. **현장 용어 → 쉬운 한국어 변환**
   - 직접 만든 현장 용어 사전(30개)으로 바꿉니다. 예: 시마이 → 마무리, 기리까이 → 교체
   - 바뀐 단어는 원문과 나란히 노란색으로 표시됩니다.
   - 바뀐 단어에 맞춰 조사도 고칩니다. 예: "빵꾸가" → "구멍이", "잔업이야" → "연장 근무야"
2. **근로자별 모국어 카드**
   - 받는 사람의 언어(베트남어·네팔어·우즈베크어)로만 번역을 골라 보냅니다.
   - 안전 지시는 빨간 테두리와 모국어 경고 문구가 붙습니다.
   - 카드에는 모국어를 크게, 쉬운 한국어를 그 아래에 보여 줍니다.
3. **이해 확인판**
   - 근로자가 카드에서 [이해했어요] / [모르겠어요]를 누르면 반장 확인판에 모입니다.
   - 지시별 이해율(%)을 보여 주고, "모르겠음"은 표 맨 위에 빨갛게 표시합니다.

그 밖에 용어 사전 추가·수정·삭제 화면과, 반장(비밀번호)·근로자(이름 선택)가 따로 들어가는 로그인 화면이 있습니다.

## 화면

| 누가 | 화면 | 하는 일 |
|---|---|---|
| 반장 | 지시 작성 | 원문 입력 → 바뀐 단어 · 쉬운 한국어 · 언어별 번역 미리보기 → 보내기 |
| 반장 | 확인판 | 지시별 이해율, 근로자별 ✓ 이해 / ? 모르겠음 / – 미확인 |
| 반장 | 용어 사전 | 현장 용어 추가 · 수정 · 삭제 |
| 근로자 | 내 지시 카드 | 모국어 카드 확인, [이해했어요] / [모르겠어요] |

## 동작 방식: 규칙과 AI 나누기

| 일 | 처리 방법 |
|---|---|
| 용어 바꾸기, 언어 나누기, 응답 세기 | **규칙** (사전 · 조건문) |
| 번역 | 미리 번역해 둔 **템플릿**에서 가장 비슷한 문장(60% 이상)을 찾아 씀 |
| 템플릿에 없는 지시 | (선택) **AI**가 다듬고 번역. 반장이 "한국어로 되옮긴 뜻"을 확인하고 체크해야만 보낼 수 있음 |

뜻이 반대로 갈 위험을 막으려고, 비슷한 템플릿이 없거나 숫자(시간·수량)가 다르면 템플릿 번역을 쓰지 않습니다.

## 실행 방법

서버 프로그램이나 설치가 필요 없는 HTML · CSS · JavaScript 앱입니다. `public/` 폴더만 웹 서버로 열면 됩니다.

```bash
cd public
python3 -m http.server 5500 --bind 127.0.0.1
```

브라우저에서 `http://localhost:5500`을 엽니다. VS Code의 Live Server 확장으로 `public/index.html`을 열어도 됩니다.

### 시연용 로그인

- **반장**: 비밀번호 `1234` (`public/data.js`의 `ADMIN_PIN`)
- **근로자**: 이름 버튼을 누르면 들어갑니다.

로그인은 브라우저 탭마다 따로 저장됩니다. 한 탭은 반장, 다른 탭은 근로자로 열어 두 화면을 오가며 시연할 수 있습니다. 반장 화면 오른쪽 위 **[↺ 초기화]**를 누르면 예시 지시 3건이 들어 있는 처음 상태로 돌아갑니다.

> 이 로그인은 서버 없이 화면을 역할별로 나누는 **시연용**입니다. 실제 보안 로그인이 아닙니다.

## 폴더 구조

```
├── public/                  웹 화면 (이 폴더만 웹 서버로 내보냄)
│   ├── index.html           화면 구조 (로그인 · 지시 작성 · 근로자 카드 · 확인판 · 용어 사전)
│   ├── style.css            디자인 (큰 글씨 · 큰 버튼 · 휴대폰 화면 대응)
│   ├── data.js              용어 사전 30개 · 근로자 8명 · 시연용 지시 10건과 번역
│   └── app.js               모든 동작 (변환 · 카드 · 저장 · 집계 · 로그인)
├── supabase-translate.ts    AI 번역 중계 함수 (Supabase Edge Function용, 선택)
├── db/
│   ├── schema.sql           데이터베이스 테이블 설계
│   ├── seed.sql             예시 데이터 (make-seed.js가 자동 생성)
│   └── make-seed.js         data.js로 seed.sql을 만드는 스크립트
├── PRD.md                   기획 문서 · 개발 순서 · 발표 시연 순서
└── .env.sample              환경변수 견본 (실제 .env는 올리지 않음)
```

## 데이터 저장

- 앱은 지금 **브라우저 localStorage**에 지시 · 카드 · 응답을 저장합니다. 같은 브라우저의 탭끼리는 바로 공유되지만, **다른 기기끼리는 공유되지 않습니다.**
- `db/schema.sql`에는 여러 기기에서 같이 쓰기 위한 테이블 설계(`workers`, `terms`, `instruction_templates`, `instructions`, `cards`)가 있습니다. Supabase에 테이블을 만들어 두었지만, 앱은 아직 이 DB를 쓰지 않습니다.

```bash
# 예시 데이터 다시 만들기 (data.js를 고친 뒤)
node db/make-seed.js
# DB에 테이블과 예시 데이터 넣기
psql "$DATABASE_URL" -f db/schema.sql
psql "$DATABASE_URL" -f db/seed.sql
```

## AI 번역 연결하기 (선택)

AI 없이도 모든 기능이 템플릿 번역으로 동작합니다. 템플릿에 없는 지시까지 번역하려면 다음처럼 연결합니다.

1. Supabase 대시보드 → Edge Functions에 `supabase-translate.ts` 내용을 붙여넣어 배포합니다.
   - 함수 이름: `translate`
   - JWT 검증(Verify JWT)은 끕니다.
2. Edge Functions → Secrets에 `ANTHROPIC_API_KEY`를 넣습니다.
3. 배포된 함수 주소를 `public/app.js`의 `AI_URL`에 넣습니다.
4. 웹앱을 다른 주소(예: Netlify)에서 열면, 그 주소를 `supabase-translate.ts`의 `ALLOWED_ORIGINS`에 추가합니다.

브라우저는 중계 함수만 부르고, **API 키는 Supabase Secrets에만 있어서 브라우저에 드러나지 않습니다.** 함수는 Claude(`claude-opus-5-5`)로 쉬운 한국어 다듬기와 번역을 하고, 반장 확인용 "한국어 되옮김"도 함께 만듭니다.

## 한계

- 다른 기기끼리 데이터가 공유되지 않습니다. 실제 현장에서 쓰려면 DB 저장으로 바꿔야 합니다.
- 번역 템플릿과 버튼 문구는 개발자가 쓴 초안입니다. 원어민 검토가 필요합니다.
- 실시간 통역, 메신저 연동, 근태 관리는 하지 않습니다.

## 성공 기준

시연용 지시 10건에서, 이 도구로 보낸 카드의 "이해했어요" 비율이 일반 번역 앱보다 높으면 성공으로 봅니다.
